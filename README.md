# Clouding with Me!!!

**Clouding with Me!!!** is a lightweight web application that showcases GitHub repositories from `nilsonsangy` and recent videos from the KnowTree YouTube channel. The project is split between a frontend hosted on **Vercel** and **AWS Amplify**, and a backend API running on both **AWS** and **Render**, working together to serve dynamic content.

## 🌟 Features

- View public **GitHub repositories** from user [`nilsonsangy`](https://github.com/nilsonsangy)
- Watch **recent YouTube videos**
- Clean and responsive web interface using **HTML**, **CSS**, and **JavaScript**
- Backend API built with **Node.js** and **Express**
- **Frontend hosted on Vercel and AWS Amplify**
- **Backend running on both AWS and Render**

## 🛠 Technologies Used

### Frontend:
- HTML
- CSS
- JavaScript
- Hosted on [Vercel](https://vercel.com/) and [AWS Amplify](https://aws.amazon.com/amplify/)

### Backend:
- Node.js
- Express.js
- Axios (for API requests)
- Running on [Render](https://render.com/) and [AWS](https://aws.amazon.com/)

### APIs:
- [GitHub REST API](https://docs.github.com/en/rest)
- [YouTube Data API](https://developers.google.com/youtube/v3)
